# Milestone conclusion workflow

Conclude an active milestone when its question is answered, its budget is exhausted, a blocker makes the result invalid, or further work has low decision value.

## Procedure
1. Inventory attempted, valid, shortlisted, and OOS-evaluated candidates; do not omit failures.
2. Compare the result with the precommitted exit criteria, materiality threshold, and evidence boundaries.
3. Apply multiple-testing/selection-bias considerations to the strength of the conclusion.
4. Record unused budget and any early-stop rule that was activated.
5. Choose exactly one outcome: `accepted`, `rejected`, `inconclusive`, or `invalid`.
6. Summarize supporting evidence, contradictory evidence, limitations, and unresolved uncertainty without rewriting experiment records.
7. Decide whether the next deterministic action is a new milestone plan, a refresh/operational action, a capability handoff, or no further research.
8. Return the project to plan mode with exactly one next planning step.
