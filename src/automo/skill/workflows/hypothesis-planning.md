# Hypothesis planning

## Goal
Select or define the highest-value falsifiable scientific claim consistent with the project's external direction.

## Inputs
GetDone/project roadmap context when available, current research program, model graph, hypothesis tree, findings, model-pool/refresh evidence, available data/capabilities, previous attempted candidates, and remaining OOS budget.

## Procedure
1. Read project direction as prioritization context; do not encode that roadmap or milestone as scientific state.
2. Inspect unresolved hypotheses and identify the uncertainty with the highest expected decision value.
3. Decide whether the claim is model-scoped, cross-model, or system-level.
4. For model-scoped claims, bind a primary model and optional related models without changing model-graph semantics.
5. Declare local, parent, and/or system objectives and the minimum required evaluation depth.
6. Define explicit falsification/evidence expectations before experimentation.
7. Activate only one immediate scientific context for automated research execution.

## Boundaries
Do not fit models, search validation results, or inspect sealed OOS while defining a new hypothesis. Do not create a hypothesis merely because an algorithm or feature is available.
