## Design decisions

- Complete generic defaults live in Automo; downstream packages contribute thin domain plugins and can replace individual subsystems.
- uv is the canonical development tool runner.
- Ruff replaces overlapping formatter/import/lint/style tools.
- Zensical remains the docs frontend but is not a core package-release gate.

## Known limitations

- The built-in model runner is intentionally small and serves as a reference implementation; richer runners belong in later runtime evolution or plugins.
- A dependency-enabled Ruff run remains to be observed in CI/local development because the current execution environment is offline.
