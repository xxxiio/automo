# Bootstrap uv automatically

## Objective

Make `python scripts/init_dev.py` self-contained for a fresh developer checkout by installing uv with the currently selected Python when uv is missing, then continuing the normal uv sync and pre-commit hook installation.

## Acceptance criteria

- Missing uv triggers `python -m pip install uv` rather than a bootstrap error.
- Existing uv is reused without reinstalling it.
- Bootstrap continues with `uv sync` and `uv run pre-commit install`.
- The standard executable `.git/hooks/pre-commit` contract remains enforced.
- Focused and full tests pass.
