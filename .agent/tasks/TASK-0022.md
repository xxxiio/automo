# Task: Unify local and CI quality execution with tox-managed tests

## Objective

Make developer commits and GitHub Actions execute the same full-repository pre-commit gate, with tox owning pytest execution across Python 3.11, 3.12, and 3.13.

## Specification

- Replace staged-file-only Git hook behaviour with a repository-owned hook that runs `pre-commit run --all-files`.
- Keep `.pre-commit-config.yaml` as the single quality-gate definition.
- Add tox environments for Python 3.11, 3.12, and 3.13 with missing interpreters treated as failures.
- Invoke tox as a filename-independent pre-commit hook.
- Remove the separate GitHub pytest matrix and install all supported interpreters in the quality job.
- Keep package/smoke and docs as separate release jobs.
- Keep canonical developer/GitHub workflows free of uv.

## Ordered plan

1. Add tox configuration and dev dependency.
2. Add tox to pre-commit.
3. Add repository-owned full-repository Git hook and configure it from developer bootstrap.
4. Make GitHub quality run the identical command with all supported interpreters available.
5. Remove redundant CI pytest orchestration.
6. Update docs, release-contract tests, and active GetDone records.
7. Run local deterministic tests and GetDone validation.

- [x] AC-001: Local Git commit hook executes `pre-commit run --all-files --show-diff-on-failure`.
