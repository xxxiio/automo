# Task: Remove tox and simplify the test workflow

## Objective

Remove tox from Automo and use Poetry + pytest directly, with local pre-commit testing the current project interpreter and GitHub providing Python 3.11/3.12/3.13 compatibility coverage.

## Scope

- Remove tox dependency and `tox.ini`.
- Replace the tox pre-commit hook with `poetry run pytest -q`.
- Remove multi-interpreter discovery from developer bootstrap.
- Add a GitHub Python 3.11/3.12/3.13 pytest matrix.
- Update current docs, release contracts, and tests.

## Acceptance criteria

- [x] AC-001: `tox.ini` and tox dependencies are absent.
- [x] AC-002: bootstrap is stdlib-only before installing tools and does not require project dependencies.
- [x] AC-003: local pre-commit always runs `poetry run pytest -q`.
- [x] AC-004: GitHub runs `poetry run pytest -q` on Python 3.11, 3.12, and 3.13.
- [x] AC-005: no Conda-specific or tox-plugin logic is required.
