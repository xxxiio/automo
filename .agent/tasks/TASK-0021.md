# Task

## Current behaviour

TASK-0020 restored Poetry Core packaging but incorrectly kept uv in developer bootstrap, public development documentation, GitHub test/health/docs workflows, and the PyPI build workflow. Connected CI also exposed a Ruff E501 failure and a brittle test import of `scripts.init_dev`.

## Desired behaviour

Poetry is the only canonical developer, test, documentation, and package-build workflow. GitHub Actions uses Poetry and standard Python tooling only. uv is not part of user/developer or GitHub workflow. Testable bootstrap logic lives in an importable Automo module and `scripts/init_dev.py` is a thin source-checkout wrapper.

## Scope

- Remove uv from current developer/public documentation and all GitHub workflows.
- Use Poetry for developer dependency installation, pytest, documentation tooling, health execution, and release builds.
- Keep pre-commit as the independent canonical source-quality gate.
- Move bootstrap logic to `automo.dev.bootstrap` and keep `scripts/init_dev.py` thin.
- Fix current Ruff line-length findings and update regression tests.
- Update active GetDone records and release evidence for the corrected workflow.

## Out of scope

- Removing uv from historical completed reports that accurately describe prior implementation state.
- New model-research features.
- New type-checking or coverage policy.

- [x] AC-003: `scripts/init_dev.py` delegates to importable `automo.dev.bootstrap` logic that runs Poetry install and pre-commit hook installation.
