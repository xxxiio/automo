# TASK-0033 — Replace Poetry workflow with uv end to end

## Objective

Make uv the single canonical development/environment/build tool for Automo and remove Poetry from the active project contract.

## Scope

- Replace the Poetry Core backend with `uv_build`.
- Move dev/docs requirements to standardized `[dependency-groups]`.
- Make bootstrap `uv sync` plus `uv run pre-commit install`.
- Run pytest through uv from pre-commit.
- Use `astral-sh/setup-uv` and uv commands in CI and release workflows.
- Build wheel/sdist with `uv build` and smoke-install artifacts with `uv pip`.
- Update active docs and regression tests to forbid Poetry returning to the canonical workflow.
- Preserve historical completed task records unchanged.

## Acceptance criteria

- [x] AC-001: active `pyproject.toml` contains no Poetry configuration and uses `uv_build`.
- [x] AC-002: local bootstrap, pytest, pre-commit, docs, health, CI, and release commands use uv.
- [x] AC-003: GitHub retains the Python 3.11/3.12/3.13 compatibility matrix through `setup-uv`.
- [x] AC-004: active public docs describe the uv-only workflow.
- [x] AC-005: local tests/source checks pass after migration.
- [ ] AC-006: generate and commit `uv.lock` in a connected checkout, then change sync/run gates to `--locked`.
