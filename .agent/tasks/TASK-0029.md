# TASK-0029 — Restore one full tox matrix contract everywhere

## Objective

Remove environment-specific tox behavior and make the developer bootstrap self-contained. Every tox execution must run the same explicit Python 3.11, 3.12, and 3.13 environments regardless of whether the host uses Conda, system Python, pyenv, venv tooling, or GitHub Actions.

## Scope

- Keep `scripts/init_dev.py` standard-library-only before dependencies are installed.
- Bootstrap pre-commit and Poetry using the current Python, then install project dev dependencies.
- Require Python 3.11, 3.12, and 3.13 to be discoverable before bootstrap reports success.
- Run plain `poetry run tox` from pre-commit so tox executes `py311`, `py312`, and `py313` everywhere.
- Remove generic `py` selection and environment-specific tox mappings/plugins.
- Provision all three interpreters in GitHub and run the same canonical pre-commit gate.

## Acceptance criteria

- [x] AC-001: `scripts/init_dev.py` imports only the Python standard library and does not import Automo or PyYAML.
- [x] AC-002: bootstrap installs pre-commit, installs the standard hook, installs Poetry, installs dev dependencies, and checks all three Python interpreter commands.
- [x] AC-003: `tox.ini` declares `py311`, `py312`, and `py313`, with missing interpreters treated as failure.
- [x] AC-004: pre-commit invokes plain `poetry run tox`, not a selected environment.
- [x] AC-005: GitHub provisions all three supported interpreters and invokes the same full-repository pre-commit gate; no tox-gh-actions mapping or local/CI tox split exists.
